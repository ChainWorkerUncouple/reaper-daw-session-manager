## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Session Library** | Organize Reaper sessions by artist, project and version |
| **Plugin Chains** | Document FX chain configurations with settings notes |
| **Routing Templates** | Track custom routing template setups and their use cases |
| **Mix Notes** | Log mix decisions and reference track notes per session |
